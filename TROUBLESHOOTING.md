# APK не ставится — пошаговая диагностика

Сообщение «Приложение не установлено, так как несовместимо с вашим телефоном» —
это **общая заглушка**. Android показывает её для нескольких разных ошибок, и по
ней нельзя понять причину. Нужно получить **точный код ошибки**.

Ниже — три пути. Начните с шага 1: он занимает минуту.

---

## Шаг 1. Проверка: ставится ли вообще хоть какой-то APK

Установите **`Fireman_Install_Probe.apk`** из релиза.

В нём:
- **нет нативных библиотек** (`lib/` отсутствует полностью) — он не может упасть
  по ABI ни при каких обстоятельствах;
- **нет разрешений**;
- `targetSdkVersion 34`, `minSdkVersion 24`.

Это «пустышка»: если она установится и покажет текст «INSTALL PROBE: OK», значит
ваш телефон **разрешает** установку APK из неизвестных источников, и проблема
касается только самой игры.

**Результат:**

| Что произошло | Вывод | Что делать |
|---|---|---|
| Probe установился | Телефон ставит APK. Проблема только в игре (32-бит) | Шаг 3 |
| Probe НЕ установился | Телефон блокирует установку APK как таковую | Шаг 2 |

---

## Шаг 2. Если не ставится даже пустышка

Значит блокировка на стороне прошивки, а не в APK. Проверьте по порядку.

### 2.1. Google Play Защита (Play Protect)

Это самая частая причина. Play Protect сканирует APK и может отклонить
неизвестное приложение, показав «несовместимо».

1. Откройте **Google Play** → нажмите на аватар → **Play Защита**.
2. **Настройки** (шестерёнка) → выключите **«Сканировать приложения на угрозы»**
   и **«Улучшенная защита»** / «Проверять приложения перед установкой».
3. Повторите установку. В диалоге может появиться кнопка
   **«Подробнее» → «Всё равно установить»** — нажмите её.

### 2.2. Расширенная защита (Advanced Protection) — Android 16 / HiOS 16

В Android 16 и **HiOS 16** есть режим **Advanced Protection Mode**. Когда он
включён, переключатель «Установка неизвестных приложений» **становится серым**, и
установить APK невозможно вообще.

Проверьте: **Настройки → Безопасность и конфиденциальность → Расширенная
защита** (Advanced Protection). Если она включена — выключите и перезагрузитесь.

Это подтверждённое поведение: Tecno описывает эту функцию как «блокировку
установки приложений из неизвестных источников одним переключателем».

### 2.3. Анти-тампер HiOS (античит Tecno/Infinix)

Tecno и Infinix добавляют в свои оболочки проверку целостности приложений. Она
может блокировать APK, **переподписанные чужим сертификатом** — а все мои сборки
подписаны новым ключом, не ключом Magma Mobile.

Признаки: «Приложение не установлено», «Не удалось разобрать пакет», либо
приложение ставится, но падает при запуске.

Что делать:
- Установить через **ADB** — это часто обходит проверки интерфейса (см. шаг 4).
- Либо вообще не устанавливать на телефон, а запустить в виртуальной машине
  (шаг 3, вариант A).

### 2.4. Разрешение на установку для конкретного приложения

Android 8+ требует, чтобы **источник** (браузер, файловый менеджер) имел право
ставить приложения:

**Настройки → Приложения → Специальный доступ → Установка неизвестных
приложений** → выберите приложение, из которого открываете APK (Chrome, «Файлы»,
ZArchiver…) → **Разрешить из этого источника**.

### 2.5. Уже установлена другая версия

Если игра из Google Play уже стоит, а подпись другая — будет
`INSTALL_FAILED_UPDATE_INCOMPATIBLE`. Удалите старую версию.
**Внимание: удаление стирает локальные сохранения.**

### 2.6. Кэш установщика

**Настройки → Приложения → Все приложения → «Установщик пакетов» →
Хранилище → Очистить кэш** (и «Очистить данные»), затем перезагрузка.

## Шаг 3. Если телефон просто 64-битный (самый вероятный случай)

Probe установился, а игра — нет. Значит причина в том, что игра только 32-битная.

**Проверка (без компьютера):** запустите **`Fireman_ABI_Check.apk`**. Вверху
экрана будет вердикт. Если «32-BIT APPS ARE *NOT* SUPPORTED» — игра на этом
телефоне нативно запущена быть не может.

**Решение — виртуальная машина VPhoneOS.** Она ставится **из Google Play**, а
внутри неё работает Android 7.1.2 **с 32-битным окружением**.

1. Установите **VPhoneOS** из Google Play (или с <https://vphoneos.com/>).
   Это обычная установка из магазина — она не блокируется.
2. Создайте виртуальную машину: **Android 7.1.2**, архитектура
   **«64-бит и 32-бит вместе»** (не «только 64»).
3. Запустите её, дайте скачать образ. Если зависает — перезагрузите телефон и
   повторите.
4. Разрешите запрошенные права. В «Для разработчиков» включите
   **«Отключить ограничения дочерних процессов»**, если попросит.
5. Внутри виртуальной машины откройте встроенный браузер и скачайте APK игры
   **прямо внутри ВМ** — этот способ работает надёжнее импорта извне.
   Либо используйте кнопку **«Импорт»/«文件中转»** и выберите APK с телефона.
6. Установите и запустите.

Это единственный метод без root, который реально работает на 64-бит-only
устройствах. VMOS Pro, X8 Sandbox и Virtual Master так не умеют — у них нет
32-битного окружения в гостевой системе.

**Важно:** внутри ВМ вы ставите APK её собственным установщиком, поэтому
блокировки HiOS хоста на это не действуют.

## Шаг 4. Точный код ошибки через ADB (самый информативный способ)

Если есть компьютер, это даст точный ответ за минуту.

На телефоне: **Настройки → О телефоне → 7 раз нажать «Номер сборки»** → в
«Для разработчиков» включить **Отладка по USB**.

На компьютере (в папке с platform-tools):

```
adb install Fireman_1.0.9_final.apk
```

Расшифровка кодов:

| Код ошибки | Значение | Что делать |
|---|---|---|
| `INSTALL_FAILED_NO_MATCHING_ABIS` | Нет 32-битного окружения | Шаг 3 (VPhoneOS) |
| `INSTALL_FAILED_DEPRECATED_SDK_VERSION` | Слишком старый targetSdk | `adb install --bypass-low-target-sdk-block ...` |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Другая подпись | Удалить старую версию (сохранения!) |
| `INSTALL_FAILED_VERIFICATION_FAILURE` | Play Protect отклонил | Шаг 2.1 |
| `INSTALL_FAILED_USER_RESTRICTED` | Запрет прошивки | Шаг 2.2 / 2.3 |
| `INSTALL_PARSE_FAILED_*` | Файл повреждён | Перекачать, сверить SHA-256 |

Если установка через ADB проходит — значит дело было в блокировке интерфейса
установщика, и APK сам по себе исправен.

### Установка прямо с телефона, без компьютера

Приложение **Install with Options** (zacharee) + **Shizuku** позволяет выполнить
то же самое без ПК: оно показывает точный код ошибки и умеет обходить блокировку
по targetSdk. Обе программы ставятся из Google Play / GitHub.

## Что точно НЕ поможет

- **Переименование или копирование `.so`** в `lib/arm64-v8a/` — внутри 32-битный
  машинный код, 64-битный загрузчик его не исполнит.
- **Правка манифеста** с объявлением `arm64-v8a` — библиотеки останутся 32-битными.
- **Hex-правка заголовка APK** — то же самое.
- **«Конвертеры 32→64»** — таких инструментов не существует.

ARM64-версии этой игры **не существует**: последний релиз Magma Mobile — 1.0.9
(2018), собранный на Unity 5.3.8f1, где ARM64 для Android ещё не поддерживался
(он появился только в Unity 2018.2 и только для бэкенда IL2CPP).

## Быстрая сводка

| Ситуация | Действие |
|---|---|
| Не ставится даже `Fireman_Install_Probe.apk` | Шаг 2: Play Protect → Advanced Protection → анти-тампер |
| Probe ставится, игра нет, `Fireman_ABI_Check` пишет «NOT SUPPORTED» | Шаг 3: VPhoneOS |
| Probe ставится, игра нет, `ABI_Check` пишет «CAN BE INSTALLED» | Причина не в ABI — нужен код ошибки, Шаг 4 |
| Есть компьютер | Шаг 4 — сразу даст точный ответ |

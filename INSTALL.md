# Fireman 1.0.9 — установка

## Что это

Исправленная сборка старой игры **Fireman 1.0.9** (Magma Mobile).

| Параметр | Значение |
|---|---|
| Package | `com.magmamobile.game.Fireman` |
| Версия | 1.0.9 (versionCode 17) |
| Размер | 23 583 364 байт (22.49 MiB) |
| Архитектура | **только `armeabi-v7a`** (32-бит ARM) |

## Если APK не устанавливается — начните отсюда

Сначала выясните, поддерживает ли ваш телефон 32-битные приложения вообще.
Установите **`Fireman_ABI_Check.apk`** из релиза — он не содержит нативных
библиотек, поэтому ставится на любой аппарат, включая 64-бит-only. Приложение
покажет вердикт одной строкой.

- Если вердикт «32-BIT APPS CAN BE INSTALLED» — ставьте `Fireman_1.0.9_final.apk`.
- Если «32-BIT APPS ARE *NOT* SUPPORTED» — **APK тут ни при чём**: в прошивке нет
  32-битного Android. Тогда смотрите **`SOLUTIONS.md`** — там рабочий способ
  (виртуальная машина VPhoneOS) и остальные варианты.

Кратко: исправить это правкой APK невозможно. Доказательство — в
`artifacts/evidence/why_apk_rejected_64bit_only.txt`: на 64-бит-only устройстве
APK без нативных библиотек ставится, а Fireman падает с
`INSTALL_FAILED_NO_MATCHING_ABIS` (а **не** с `INSTALL_FAILED_DEPRECATED_SDK_VERSION`,
значит правило Android 15/16 по targetSdk ни при чём — у игры targetSdk 27 ≥ 24).

## Требования

Нужен Android, который умеет запускать **32-битные ARM-приложения**.

Проверьте на своём телефоне (без компьютера — см. ниже) или через adb:

```
adb shell getprop ro.product.cpu.abilist32
```

- Вернулось `armeabi-v7a,armeabi` → игра установится и запустится.
- Вернулось пусто → **игра не установится**, это ограничение прошивки, а не APK.

Также нужен Android 4.0+ (minSdk 14). Проверено на Android 11 (эмулятор).

## Установка

### Способ 1. Через телефон (без ПК)

1. Скачайте `Fireman_1.0.9_final.apk` со страницы релиза.
2. Разрешите установку из неизвестных источников для файлового менеджера или
   браузера, которым открываете файл.
3. Откройте APK и подтвердите установку.

### Способ 2. Через adb

```
adb install Fireman_1.0.9_final.apk
```

Если выдаёт `INSTALL_FAILED_NO_MATCHING_ABIS` — на устройстве нет 32-битного
userspace. Смотрите раздел «Ограничения».

### Если стоит оригинальная игра из Google Play

Подпись этой сборки **не совпадает** с подписью оригинала (оригинал подписан
ключом Magma Mobile, здесь — новый ключ). Поэтому установка «поверх» может
завершиться ошибкой `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

**Внимание: удаление установленной игры стирает её локальные сохранения.**
Прогресс и покупки в этой игре хранятся в данных приложения. Если сохранения
важны — сначала сделайте резервную копию (например, через
`adb backup` на устройстве с отладкой, или ручным копированием каталога
`/sdcard/Android/data/com.magmamobile.game.Fireman`, если он есть).
Не удаляйте игру, не убедившись, что копия сделана.

## Как проверить поддерживаемые ABI без компьютера

**Рекомендуемый способ:** установите `Fireman_ABI_Check.apk` из релиза. Он
написан так, что не содержит нативных библиотек, поэтому ставится на любое
устройство, и показывает именно список ABI Android (`Build.SUPPORTED_32_BIT_ABIS`),
а также `ro.zygote`, `abilist32` и наличие `/system/lib/libc.so`. Вверху экрана —
готовый вердикт.

Нужны именно сведения о **ABI Android userspace**, а не о процессоре.
Приложения вида «CPU Info» показывают характеристики ядра и часто пишут
«64-bit», хотя 32-битный userspace при этом отсутствует. Ориентироваться на них
нельзя — например, MT6878 аппаратно умеет 32-бит, но это ничего не говорит о том,
разрешает ли Android 32-битные приложения.

Альтернативы, если не хотите ставить APK:

1. **Терминал на телефоне** (приложение Termux, без root):
   ```
   getprop ro.product.cpu.abilist32
   getprop ro.zygote
   ```
   Пустой `abilist32` и `zygote64` означают 64-бит-only устройство.
2. **Сам факт установки.** Если `Fireman_1.0.9_final.apk` не ставится с
   `INSTALL_FAILED_NO_MATCHING_ABIS` — 32-битного окружения нет.

## Ограничения

- Сборка содержит только 32-битные библиотеки. На устройствах, где Android
  собран без 32-битного userspace (например, TECNO Pova 7 5G / LJ7,
  прошивка `sys_tssi_64_64only_*`, `abilist32` пуст), она **не установится**.
  Это ограничение совместимости, а не дефект сборки.
- ARM64-версии этой игры не существует: последний релиз Magma Mobile — 1.0.9
  (2018), собранный на Unity 5.3.8f1, где ARM64 для Android ещё не
  поддерживался. Полный ARM64-порт потребовал бы исходного проекта Unity.
- Интернет-магазин и реклама в игре могут не работать: серверы Magma Mobile и
  сторонние рекламные SDK давно отключены.
